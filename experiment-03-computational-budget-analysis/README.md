Experiment 3 analyzes the influence of computational resources on Connect Four AI performance. It compares node budgets of 3,000, 6,000, and 12,000 nodes per move using Minimax with Alpha-Beta Pruning and Iterative Deepening. The study uses three heuristic matchups, five random seeds, and 540 games to evaluate performance, computational cost, completed search depth, and budget exhaustion.
